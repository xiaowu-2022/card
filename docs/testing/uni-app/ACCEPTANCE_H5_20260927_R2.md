# 2026-09-27 uni-app H5 二轮验收与 PhotonPay 沙箱

用户明确允许 PhotonPay 测试环境运行。本轮先核对保存的 issuing/reporting/identity 地址均为 `https://x-api.sandbox.photontech.cc`，验证 USD 账户和会员归属，再运行有限的测试卡充值。Laravel 离线测试仍只使用 `card_ui_test`；实际沙箱联调使用本机 `local/card_mock` 已有测试账户和卡片。

### 当前沙箱边界

新开卡需要新的、未用于开卡的持卡人申请；当前该产品仅有的一份 READY 虚拟卡申请已经使用。本轮没有复用申请绕过“一次申请一次开卡”，没有新提交身份资料。新开卡、注销、实体卡激活和公网回调仍不能算本轮真实沙箱通过；其成功/拒绝/UNKNOWN 契约由离线测试验证。

## 本轮代码修正

1. 旧推广、保证金、激活、KYC 测试改用现行 CN 双面身份证及明确匹配的模拟 OCR 结果；保留资金、权限及幂等断言。
2. OCR 测试改为提交时同步识别，覆盖事务外调用、识别失败/不匹配/空号码、超时重提、重复提交与旧 job 不覆盖已成功结果。没有改动生产 OCR 门禁。
3. 保证金退款路由断言纳入已存在的客户端 API 路由。
4. 实际 H5 检查发现客服等加载状态缺少 `Loading…` 翻译，补充中文、马来语、西班牙语共用文案。
5. 新增检查发现的 PhotonPay 旧测试改用已验证的账户配置、含账户命名空间的 token 缓存键和账户专属回调 URL；保留真实签名验证、错误码及脱敏断言，并增加未验证账户拒绝路由的场景。生产域名的路由测试完全离线，不发起生产请求。
6. 增加限定本机测试库的沙箱验证脚本；报告仅输出安全状态、金额和内部记录 ID，不输出凭据、证件、完整卡号或 CVV。
