# Platform UI 改版交付（2026-10-10）

## 范围和发布

本次只调整 `/platform` 展示与交互组件。没有 PHP、业务 API、数据库、资金算法、权限定义、队列或定时任务变更。公司后台独立页面、H5 和 APK 不需要重建。

发布文件：完整 `public/build/`，包含 `manifest.json` 和全部哈希资源。
交付包：`artifacts/platform-redesign/platform-admin-build.tar.gz`；同目录提供 SHA-256。

沿用现有运维的版本目录与原子切换流程：

1. 校验构建包 SHA-256，解压到待发布版本目录（包内路径为 `public/build/`）。
2. 同一版本内一起发布 manifest 和全部 assets，不单独替换 CSS 或 JS。保留上一版本资源直到已有浏览器完成刷新。
3. 切换版本后刷新后台，检查用户、公司、卡片和系统配置；如有 CDN，按既有流程刷新 manifest/HTML 缓存。
4. 回滚时恢复上一版本完整 `public/build/`。本次不需要迁移、资金修复、清空 Redis 或重启扫描任务。

未执行线上部署。构建包仅含静态资源，不含部署凭据、环境配置或测试截图。

## 变更

- 导航分成工作台、客户运营、资金与卡片、平台管理，保留原路由与权限；隐藏没有可见项目的分组。
- Platform 专用浅灰背景、白色工作区、蓝色主操作；224px 桌面侧栏、56px 顶栏、20px 正文边距。小屏主操作移到正文顶部，导航和语言入口保留在侧栏菜单。
- 标题、分区、正文和说明分别为 20/18/14/12px；控件 36px。按钮不收缩或拆字，组内允许换行。
- 公共表格内部滚动，可键盘聚焦。金额采用等宽数字并右对齐，日期分两行减少列宽，长文本保留完整 title。用户身份列桌面固定，小屏取消固定以留足阅读空间。
- `PlatformAccountTable` 新增可选 `align`、`pin` 列配置和 `advanced` 筛选配置。客服用户、订单网络等低频条件进入更多筛选；当前已应用条件独立显示，可重置。分页与 URL 状态仍由原请求处理。
- 客户详情保留账号、资金、推广三个分区、原有选项卡及底部操作。字段网格按抽屉实际空间排列，备注和邀请码仍在字段旁修改。
- `DialogContent` 新增可选 `presentation="drawer"`，只在 Platform 上下文生效；其他端默认行为保持兼容。产品、通知、管理员、域名、卡商、合伙人编辑及通用编辑器采用右侧工作区。确认和操作结果继续居中，成功／失败仍须点确定关闭。
- 公司配置沿用分类、懒加载、修订与脏数据保护；保留保存区和焦点恢复。字段标签与说明统一层级。
- 概览先显示统计，再筛选和趋势；原指标、口径与钻取不变。合伙人报表移除渐变和绿色装饰，采用白色统计区及蓝色链接。
- 客服取消 900px 强制最小宽度，窄屏上下排列。USDT 展示仍为 U，实际币种参数、金额精度不变。

既有失败（本次未修改对应业务实现）：

- 国际化测试仍在 Topups 页面内寻找已抽离的手动确认路由字符串。
- `KycApplicationDialog.tsx` 的 `Loading...` 缺少对应文案。
- 消费者 `PartnerStockReport.tsx` 中 `›` 被静态检查视为未翻译文字。
- 消费者 KYC 上传原件错误缺少完整多语言文案。

本次修复了国际化测试加载器未解析 `admin-asset-label` 的问题，并按既有 U 展示规则更新断言。旧 `admin-list-dialogs.mjs` 在操作结果弹窗遮挡旧对话框时停止，脚本仍使用旧操作反馈断言；本次公司配置及新增响应式套件覆盖了对应的新流程。构建还有既有的单个图片运行时解析提示及大型 i18n chunk 提示。
