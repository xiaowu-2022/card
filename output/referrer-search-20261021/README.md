# 修改推荐人下拉搜索

修改推荐人直接在下拉框搜索、选择并确认。支持姓名、邮箱、账号 ID、用户或推广成员 UUID
片段匹配；无需搜索后刷新编辑区，原因保留。支持候选分页、重试及取消过期请求。
同公司、有效用户、排除本人/当前推荐人/下级的限制与原有提交锁、版本检查、幂等和审计保持。

同时落实总览显示调整的补充口径：仅影响累计实际充值金额，当天及近期周期不变。
日期只用作记录信息。该项需新增显示调整日志迁移，推荐人搜索自身无需迁移。

部署 PHP 与匹配的 admin-build 后台资源，保留旧哈希并最后更新入口/manifest。
本次后台交互修改无需 H5 或原生重编译。未部署生产、未调整真实推荐关系或资金，
未调用供应商。其他既有工作区功能仍须按各自文档协调发布。

隔离数据库测试、离线浏览器、类型检查和后台构建结果见 verification.json 与日志。
