# 实际充值金额显示调整

后台总览“实际充值金额”增加“调整及记录”。可输入非零正负 U 金额，填写调整日期
和原因，并确认提交。每笔保留金额、日期、原因、操作人和登记时间；历史不可改删，
纠错追加反向调整。按用户补充要求，金额仅计入累计实际充值金额；当天和各近期周期保持不变，日期只用于记录。

只改变本总览的显示值及其来源说明；不改充值订单、到账类型、公司/用户充值合计、
历史资金分析、预支、钱包或 Ledger。来源弹窗分开列出原始充值和显示调整，支持独立
编号分页，且金额在同一读取快照中核对。没有汇率证据的原始估值继续显示不可用。
